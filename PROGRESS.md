## Каталог (katalog.html)
- Сверху — 11 крупных плиток категорий с обложками (8 ESPA на синем градиенте, 3 Hidrostal на тёмно-синем). Клик по плитке ставит фильтр по категории и прокручивает к сетке серий.
- Ниже — слева панель фильтров (поиск, бренд, категории с количеством, «Подача Q от» / «Напор H от» по максимумам серии), справа сетка серий, чипы активных фильтров, пустое состояние. На мобильном фильтры сворачиваются в кнопку «Фильтры», плитки — горизонтальная лента.
- Хеш в URL: `#espa-stancii` открывает категорию, `#espa` / `#hidrostal` — фильтр по бренду (на это ссылаются товарные страницы, меню, футер).
- Обложки: `tools/build-covers.py` (Pillow) вырезает фон у фото серий и собирает 1–3 насоса → `assets/img/cats/<brand>-<категория>.webp`. Состав обложек — словарь `COVERS` в скрипте.
- Технические данные товаров — с официальных сайтов ESPA (espa.com/uk) и Hidrostal; ссылки на PDF-каталоги производителей оставлены второстепенными.

## Генераторы и команды
- `python3 tools/sync-chrome.py` — копирует шапку/футер/скрипты (`<!-- chrome:* -->` из index.html) во все страницы, включая `product/`.
- `python3 tools/scrape-espa.py` — данные ESPA → `data/espa-raw.json` + фото.
- `tools/catalog_data.py` — переводы, категории, данные Hidrostal, `ESPA_EXCLUDE` (Sub-tank FS/VS убраны по решению клиента 26.10.2026).
- `python3 tools/build-catalog.py` — страницы `product/*.html`, блоки `gen:cats-*`, `gen:fcats-*`, `gen:products` в katalog.html, `data/catalog.json`.
- `<venv>/bin/python tools/build-covers.py` — обложки категорий (нужен Pillow; venv в scratchpad сессии, при необходимости `python3 -m venv … && pip install pillow`).
- Превью: `.claude/launch.json`, конфиг `static` (`python3 -m http.server 8787`).
- При правке CSS/JS — поднимать `main.css?v=` / `main.js?v=` в index.html и запускать sync-chrome.

## Ключевые решения
- Стек макета: HTML + Tailwind CDN (конфиг в `<head>`) + свой `assets/css/main.css`; GSAP + ScrollTrigger (`.rv`, `.rv-group` с `clearProps`, `[data-slide]`), hero — CSS keyframes.
- Шрифты Geologica (заголовки) + Onest (текст).
- Палитра из логотипа (CDR клиента): blue `#1D3C8D`, cyan `#008AC7` (мелкий текст `#0074A8`), navy `#0F1C3E`, акцент на тёмном `#4CBFF0`. На тёмных фонах `.btn-primary` светло-голубая с тёмным текстом.
- Логотип АТЕ — из CDR клиента (`tools/build-logo.py`, исходник `assets/logo/source/`). Иконки — Lucide + Simple Icons спрайтом в chrome:top (не рисовать вручную).
- Попап заявки `[data-lead-modal]`: ссылки с `data-popup="lead"`, `data-popup-title`, `data-popup-dir`, `data-popup-note`.
